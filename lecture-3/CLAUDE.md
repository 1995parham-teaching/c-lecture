Scheduled for **3 sessions**, assessed by **HW2**.

1. What is the C
2. Structure
3. Variables
4. Values

Each one produces an outline divider automatically, from the
`\AtBeginSection` hook in `../c-lecture.cls`.

## Notes

The first deck that compiles anything, and where the `output` minted language
starts being used to separate a program from what it prints. Three sessions
for six sections — the _Values_ and _Casting_ sections are where students lose
the most time.
